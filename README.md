# ePay

A Flutter-based payment app for web and mobile platforms.

## Overview

ePay is a simple Flutter application designed to facilitate secure payments. It demonstrates the use of Flutter web, mobile, and desktop support, with a clean UI and responsive design.

## Features

- User-friendly interface
- Responsive design for web and mobile
- Payment simulation functionality
- Flutter Web deployment ready
